# Security policy

## Reporting a vulnerability

**Don't open a public issue.** Report it privately through GitHub: this
repository's **Security** tab → **Report a vulnerability**. Only the
maintainers see the report.

Include the page or file affected, the steps to reproduce it, and what an
attacker gains. You'll get an acknowledgement, then updates until it's fixed
or declined. Once a fix is released, it's published as a GitHub security
advisory, crediting you unless you'd rather not be named.

A wrong price isn't a vulnerability: open a **Price correction** issue.
