# Governance

## Who maintains it

The maintainers are listed in [.github/CODEOWNERS](.github/CODEOWNERS). Today they all work at
[Telflo](https://telflo.com), which started the project and pays for the site. Telflo does not
sell an observability platform. It is used to change where telemetry is sent, so it gains when
teams compare platforms.

We want maintainers from outside Telflo. If you have had several corrections or an adapter
merged, open an issue to ask. The existing maintainers decide by majority.

## What cannot be bought

- A place on the list. Any product with public prices can be added.
- A number. Prices come only from the vendor's public pages.
- An assumption. The conventions are the same for every platform.
- A position. The visitor sorts the list. The default is lowest estimate first.

No maintainer may accept payment, credits or gifts from a vendor in connection with this
project.

## How changes are decided

**A price correction.** A maintainer opens the public page cited in the pull request. If it
matches, it is merged.

**A new platform.** A maintainer checks the sources and worked examples and runs the contract
checks. A product priced by quote is listed as not priced.

**A method change.** A change that moves more than one platform's numbers is proposed in a public
issue and stays open for seven days. It applies to every platform at once and is recorded in
[PRICE-LOG.md](PRICE-LOG.md).

**A dispute.** If a vendor says an estimate misreads its pricing, we ask for the public page that
shows the right reading. If the page can be read both ways, we use the reading that matches the
vendor's calculator or worked example, and the receipt says so.

## Contributions from vendors

Vendor employees are welcome. Say who you work for in the pull request. A vendor cannot review or
merge a change to its file.

## Corrections and takedowns

Report a wrong number with a Price correction issue. Open an issue as well if you believe a
product name or description is used wrongly.
